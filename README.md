# ResumeCraft 📄

ResumeCraft is a modern, AI-powered resume builder and analyzer that helps users create professional resumes and optimize them for Applicant Tracking Systems (ATS).

## 🌟 Features

### Resume Creation   
- AI-powered resume builder  
- Real-time ATS score analysis
- Multiple professional templates
- Content extraction from existing resumes  
- Smart content suggestions
- Live preview while editing

### Resume Analysis  
- Comprehensive ATS compatibility check
- Detailed scoring system
- AI-powered improvement suggestions using Gemini Flash model
- Keyword optimization recommendations

### Additional Features
- User authentication system
- Responsive design
- Dark/Light mode support
- PDF export functionality
- Cloud storage for resumes
